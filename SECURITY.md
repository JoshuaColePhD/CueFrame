# Security policy

CueFrame is a local macOS screen recorder. It records the screen, camera, and microphone only after macOS permission prompts, and stores recordings on the Mac. Optional AI edit suggestions send screen samples, click coordinates, and microphone audio directly to OpenAI, using an API key the user stores in the macOS Keychain, and only when the user chooses **Generate AI Edit**.

## Supported versions

Security fixes are made on the `main` branch of this fork.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's [private vulnerability reporting](../../security/advisories/new) or by email to joshuacolephd@gmail.com. Please do not open a public issue for security reports. I aim to acknowledge reports within five business days.

Issues that also affect the upstream project, [danieloquelis/EasyDemo](https://github.com/danieloquelis/EasyDemo), may be shared with its maintainer after a fix is available.
